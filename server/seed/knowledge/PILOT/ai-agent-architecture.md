# AI Agent Architecture & Multi-Tool Orchestration

## Overview
ProjectPilot incorporates a multi-turn AI reasoning agent powered by `AiAgentService` and Google Gemini (`@google/genai`). The agent acts as an intelligent operational assistant capable of answering complex project management questions, evaluating risk, correlating live operational database records with RAG document knowledge, and producing structured evidence-backed analysis.

## Approved Read-Only Tool Allowlist
To guarantee security and project integrity, the AI agent is restricted strictly to **7 approved read-only tools**. Mutation operations (creating/deleting tickets or changing sprint dates) via AI tools are explicitly prohibited.

1. **`list_project_tickets`**: Fetches normalized tickets for a project workspace (filtered by status, priority, or assignee).
2. **`get_ticket_details`**: Retrieves comprehensive details for a specific ticket by key (e.g., `PILOT-101`), including description, status, comments, and story points.
3. **`get_sprint_progress`**: Calculates sprint completion metrics, story point totals, completed vs remaining points, and burndown pace.
4. **`list_sprint_tickets`**: Lists all tickets assigned to a specific sprint.
5. **`get_project_activity`**: Retrieves recent operational audit log activity for a project workspace.
6. **`get_project_summary`**: Generates a high-level project status summary combining ticket counts, sprint status, and team capacity.
7. **`search_project_knowledge`**: Performs RAG semantic vector search against indexed project documentation using pgvector cosine distance.

## Multi-Turn Reasoning Loop (`AiAgentService`)
1. **Request Initialization**: The agent initializes contents with system instructions generated by `AgentPlanner` and conversation history.
2. **Turn Execution**: The agent calls Gemini with available tool declarations.
3. **Tool Execution & Validation**: If Gemini requests tool calls, `ToolExecutor` validates arguments, verifies project authorization, executes the read-only operational repository call, and returns sanitized results.
4. **Evidence Synthesis**: If tool results are returned, the agent feeds findings back to Gemini for subsequent reasoning rounds (up to `MAX_AGENT_ROUNDS = 5`).
5. **Final Output Formatting**: `agentResponse` sanitizes final output, attaches citations (`sources`), formats structured risk analysis (`analysis`), and records telemetry metrics.

## Production Safety Controls & Hardening
- **Gemini Timeout**: 15 seconds per API request.
- **Agent Execution Timeout**: 30 seconds overall wall-clock limit.
- **Max Tool Executions**: Capped at 10 tool calls per user turn.
- **Context Budget**: Messages exceeding 24,000 characters trigger context window pruning, retaining system instructions and the latest user prompt while dropping oldest historical turns.
- **Concurrency Limit**: Server limits concurrent active AI agent requests to 10.
